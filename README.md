# STM32 Device Driver Demo

This repository demonstrates a custom device driver implementation for STM32 microcontrollers.  
It showcases low-level embedded programming, hardware abstraction, and integration with peripheral interfaces.

## Features
- GPIO driver for input/output control
- UART driver for serial communication
- CAN bus driver for ECU simulation
- Modular code structure with clear separation of layers

## Tools & Environment
- STM32CubeIDE / Keil uVision
- STM32CubeMX for peripheral initialization
- GCC ARM toolchain
- Tested on STM32 Nucleo board

## How to Run
1. Clone this repository
2. Open in STM32CubeIDE
3. Build and flash firmware to your STM32 board
4. Connect via UART or CAN to observe driver functionality

## Learning Outcomes
- Low level register programming
- Embedded driver development
- AUTOSAR style modularity
